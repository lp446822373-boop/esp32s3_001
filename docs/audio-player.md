# 串口音频播放模块协议参考

本文档根据模块厂商资料整理，适用于 **M09 / WTS 系列串口音频播放模块**（本项目实测版本返回 `WTS240514-72-A01V3.00`），方便后续开发查询。

## 1. 串口参数

| 项目 | 值 |
| --- | --- |
| 波特率 | 115200（默认，可切换） |
| 数据位 | 8 |
| 校验 | 无 |
| 停止位 | 1 |
| 流控 | 无 |

模块上电默认波特率 115200。`FB` 指令可切换，但**掉电不记忆**。

## 2. 帧格式

所有指令采用统一帧格式：

```
7E  LEN  CMD  PARAM...  SUM  EF
```

| 字段 | 说明 |
| --- | --- |
| `7E` | 起始码 |
| `LEN` | 长度 = `LEN` 自身 + `CMD` + 参数 + `SUM` 的字节总数，即 `参数个数 + 3` |
| `CMD` | 命令码 |
| `PARAM` | 参数，长度由命令决定，可为 0 字节 |
| `SUM` | 校验码 = `(LEN + CMD + 所有参数)` 的低字节（不包含 `SUM` 和 `EF`） |
| `EF` | 结束码 |

示例：播放第 1 首

```
7E 05 A0 00 01 A6 EF
```

校验：`0x05 + 0xA0 + 0x00 + 0x01 = 0xA6`。

回包通常为 4 字节长度：

```
7E 04 CMD 00 SUM EF     // 通用应答，SUM = 04 + CMD + 00
```

查询类指令的回包在 `00` 位置返回具体数据。

## 3. 指令速查表

| 命令码 | 功能 | 发送帧 | 参数 | 掉电记忆 |
| --- | --- | --- | --- | --- |
| `A0` | 指定 Flash 根目录索引播放 | `7E 05 A0 曲目高 曲目低 SUM EF` | 16 位曲目号，高字节在前 | 否 |
| `A1` | 指定文件名播放 | `7E LEN A1 文件名... SUM EF` | 文件名 ASCII，≤ 8 字节 | 否 |
| `AA` | 暂停 / 继续 | `7E 03 AA AD EF` | 无 | 否 |
| `AB` | 停止播放 | `7E 03 AB AE EF` | 无 | 否 |
| `AC` | 下一曲 | `7E 03 AC AF EF` | 无 | 否 |
| `AD` | 上一曲 | `7E 03 AD B0 EF` | 无 | 否 |
| `AE` | 音量控制 | `7E 04 AE 音量 SUM EF` | 0~31 | **是** |
| `AF` | 指定播放模式 | `7E 04 AF 模式 SUM EF` | 00~03 | 否 |
| `C0` | 查询软件版本 | `7E 03 C0 C3 EF` | 无 | — |
| `C1` | 查询当前音量 | `7E 03 C1 C4 EF` | 无 | — |
| `C2` | 读取当前工作状态 | `7E 03 C2 C5 EF` | 无 | — |
| `CA` | 查询外设连接状态 | `7E 03 CA CD EF` | 无 | — |
| `FB` | 波特率切换 | `7E 06 FB 波特率3字节 SUM EF` | 大端 24 位 | 否 |

> 说明：M09 模块面向个人开发者暂不支持固定语音定制；设置播放模式对内置固定语音无效。

## 4. 指令详解

### A0 指定 Flash 根目录索引播放

```
发送：7E 05 A0 00 01 A6 EF      // 播放第 1 首
应答：7E 04 A0 00 A4 EF
```

曲目号 16 位，高字节在前。参数个数为 2，因此 `LEN = 05`。

### A1 指定文件名播放

文件名使用 ASCII 码，**长度不超过 8 字节**，中文一个字符占 2 字节。

```
发送：7E 07 A1 30 30 30 31 69 EF              // 播放 0001.mp3
发送：7E 0B A1 30 30 30 30 30 30 30 31 2D EF  // 播放 00000001.mp3
应答：7E 04 A1 00 A5 EF
```

### AA 暂停 / 继续

```
发送：7E 03 AA AD EF
应答：7E 04 AA 00 AE EF
```

- 播放状态下发送：暂停
- 暂停状态下发送：从暂停处继续
- **停止状态下发送：无效**（需要先用 `A0` / `A1` 开始播放）

### AB 停止播放

```
发送：7E 03 AB AE EF
应答：7E 04 AB 00 AF EF
```

停止当前正在播放的音乐。

### AC 下一曲

```
发送：7E 03 AC AF EF
应答：7E 04 AC 00 B0 EF
```

- 触发播放当前目录下的下一曲
- 播放最后一曲时跳回第一曲
- 不支持内置固定语音的"下一曲"
- 上电默认 Flash 下一曲
- 播放文件夹内音频时，下一曲固定在文件夹内循环

### AD 上一曲

```
发送：7E 03 AD B0 EF
应答：7E 04 AD 00 B1 EF
```

- 触发播放当前目录下的上一曲
- 播放第一曲时跳到最后一曲
- 不支持内置固定语音的"上一曲"
- 上电默认 Flash 上一曲
- 播放文件夹内音频时，上一曲固定在文件夹内循环

### AE 音量控制（掉电记忆）

```
发送：7E 04 AE 1F D1 EF      // 设置最大音量 31
应答：7E 04 AE 00 B2 EF
```

音量共 32 级（0~31）：

- `00`：静音
- `1F`（31）：最大音量

可实时调节，并具有掉电记忆。

### AF 指定播放模式（无掉电记忆）

在通电情况下修改播放模式，**掉电后恢复默认模式**（上电默认单曲不循环）。

| 模式 | 说明 | 发送帧 |
| --- | --- | --- |
| `00` | 单曲不循环（上电默认） | `7E 04 AF 00 B3 EF` |
| `01` | 单曲循环 | `7E 04 AF 01 B4 EF` |
| `02` | 所有曲目循环 | `7E 04 AF 02 B5 EF` |
| `03` | 随机模式 | `7E 04 AF 03 B6 EF` |

应答：`7E 04 AF 00 B3 EF`。

随机模式说明：随机播放所有曲目。例如文件内有 5 首音频，先设置播放 `01` 地址、再设置随机模式，播放完 `01` 后会随机跳到 `03` 或其他地址，而非按 `02→03→04→05` 顺序播放。

### C0 查询当前软件版本

```
发送：7E 03 C0 C3 EF
应答：7E 18 57 54 53 32 34 30 35 31 34 2D 37 32 2D 41 30 31 56 33 2E 30 30 82 EF
```

返回的 16 进制转字符串为 `WTS240514-72-A01V3.00`：

- `WTS`：公司代码
- `240514`：2024 年 05 月 14 日发布的版本程序
- `72`：公司内部代码
- `A01`：选型表功能代码
- `V3.00`：版本号

### C1 查询当前设置音量

```
发送：7E 03 C1 C4 EF
应答：7E 04 C1 1F E4 EF      // 1F = 31 级（最大）
```

### C2 读取当前工作状态

```
发送：7E 03 C2 C5 EF
应答：7E 04 C2 02 C8 EF      // 停止状态
```

状态码：

| 值 | 状态 |
| --- | --- |
| `01` | 播放 |
| `02` | 停止 |
| `03` | 暂停 |

示例返回 `02`，表示播放过程中发送过停止（`AB`）指令后处于停止状态。

### CA 查询当前外设连接状态

```
发送：7E 03 CA CD EF
应答：7E 04 CA 05 D3 EF      // 同时挂载 Flash 与 U 盘
```

返回值低 4 位表示外设存在状态（0 不存在 / 1 存在）：

| 位 | 外设 |
| --- | --- |
| BIT3 | PC 连接 |
| BIT2 | U 盘 |
| BIT1 | SD 卡 |
| BIT0 | SPI-FLASH |

示例：

- `0x01`：无 PC / 无 U 盘 / 无 SD 卡 / 有 SPI-FLASH
- `0x07`：无 PC / 有 U 盘 / 有 SD 卡 / 有 SPI-FLASH

### FB 波特率切换（无掉电记忆）

```
发送：7E 06 FB 00 25 80 A6 EF    // 设置波特率 9600
应答：7E 04 FB 00 FF EF
```

- 参数为 24 位大端十六进制，范围 **4800~921600 bps**（误差 5% 左右）
- 示例中 `0x002580 = 9600`
- 上电默认 115200
- 切换后芯片波特率**立即更新**

使用要点：

- 若当前通信为 9600，发送 `FB` 切到 115200 后 MCU 仍为 9600，收发都会异常
- 一般需在 **100 ms 内同步修改 MCU 的串口波特率**，初次设置才能正确收到 `7E 04 FB 00 FF EF`
- 波特率设置越高，需确认主控 MCU 支持的最高波特率及频偏范围

## 6. 在项目中的实现

本项目在 [main/player.c](../main/player.c) 中实现了协议收发：

- UART0：TX = GPIO43，RX = GPIO44，115200 8N1
- `send_cmd()` 负责组帧与校验
- `player_rx_task()` 负责解析回包、校验 `SUM`，并同步播放状态与音量
- 每 2 秒发送一次 `C2` 查询状态，避免歌曲播完后本地状态与实际不一致
- 上电发送一次 `C1` 查询当前音量，与模块的掉电记忆值同步
- 按键行为映射：
  - GPIO4 短按：播放中 → `AA` 暂停；暂停中 → `AA` 继续；停止 → `A0 00 01` 播放第 1 首
  - GPIO4 长按（≥ 0.8 s）：`AC` 下一首
  - GPIO5 短按：`AE` 音量减 1 级
  - GPIO5 长按（≥ 0.8 s）：`AE` 音量加 1 级，按住期间每 200 ms 再加 1 级
